# Chromatofoor Procedural Macros (`chromatofoor-derive`)

## Overview
`chromatofoor-derive` (`proc-macro = true`, re-exported from `chromatofoor`) implements the 18 canonical `#[chromatofoor::<kind>]` procedural attribute macros corresponding to ESDM (`schemas/core/v1.yaml` and `schemas/lifecycle/v1.yaml`). At compile time, it synthesizes `chromatofoor` domain/runtime metadata traits, `architecturekit` event-sourcing and projection plumbing, `serde`/`validator` derives, and static const/trait assertions enforcing hierarchical `Scope` boundaries, `Identified` field contracts, aggregate lifecycle preconditions, external-system directions, and fail-closed `Authorized` actor lists.

## Interface
- **Strategic DDD Macros** (`src/lib.rs`, `src/domain.rs`, `src/bounded_context.rs`):
  - `#[domain]` — Marks a root problem-space type (`Scope = ()`, `TOPIC = "/<kebab-name>"`), implementing `Kind` and `Domain`.
  - `#[subdomain(scope = <Domain>, type = core | supporting | generic, bounded_contexts = [<BC>, ...])]` — Implements `Kind` and `Subdomain` (requires non-empty `bounded_contexts`).
  - `#[bounded_context(scope = <Domain>)]` — Implements `Kind`, `BoundedContext`, `EventStructScope`, and `MappingEndpoint`.
- **Tactical Bounded-Context Macros** (`src/lib.rs`, `src/bounded_context.rs`):
  - `#[aggregate(scope = <BC>, identified_by = <spec> | [<spec>, ...])]` — Implements `Kind`, `Identified` (`HAS_LIFECYCLE = true`; defaults `identified_by` to `generated(uuid)`), `CommandScope`, `Aggregate`, and `EventStructScope`.
  - `#[dynamic_consistency_boundary(scope = <BC>, identified_by = ..., consults = [<Event>, ...])]` — Requires non-empty `consults` and defaults optional `identified_by` to `generated(uuid)`; implements `Kind`, `Identified` (`HAS_LIFECYCLE = false`), `architecturekit::State`, `CommandScope`, `DynamicConsistencyBoundary`, and generates `<Ident>Event` (`DcbEvents`).
  - `#[event(scope = <Aggregate | BC>)]` — Derives `Clone, Debug, PartialEq, Serialize, Deserialize, architecturekit::Schema` (normalizing unit structs to `{}`). On an `enum` (`scope = <Aggregate>`, requiring at least one variant), expands named/unit variants into standalone event structs (while delegating 1-field tuple variants `Variant(Inner)`), derives `architecturekit::Events` + `From<Variant>`, and implements `architecturekit::State` on `<Aggregate>` delegating to `Event::evolve`; on a `struct` (`scope = <BC | Aggregate>`), implements `Kind`, `architecturekit::Event`, `EventInBoundedContext`, and `EventInDomain`.
  - `#[command(scope = <Aggregate | DCB>, creates, lifecycle = create | mutate, actors = [<Actor>, ...], error = <Err>, validate)]` — Supports structs and enums (plus helper attributes `#[creates]`, `#[lifecycle(create)]`, and `#[actors(<Actor>, ...)]`; `error = <Err>` is enum-only). Derives `Clone, Debug, PartialEq, Serialize, Deserialize` (+ `Schema` and optional `validator::Validate`, normalizing unit structs to `{}`); implements `Kind`, `architecturekit::Command`, `ValidatePayload`, and `Authorized` on both structs and enums, `CommandInDomain` on command structs and generated per-variant structs (not on command enums), and `Command<Scope>` on command enums (when non-empty or when `error = <Err>` is provided).
  - `#[read_model(scope = <BC>, events = [<Event>, ...])]` — Requires non-empty `events`; implements `Kind`, `ReadModel`, generates `<Ident>Events`, and implements `architecturekit::Projection` delegating to `Project<E>::project` and `.seen(event_id)` on each struct field.
  - `#[query(scope = <BC>, actors = [<Actor>, ...])]` — Supports struct-level `#[actors(...)]`, normalizes unit structs to `{}`, derives `Clone, Debug, PartialEq, Serialize, Deserialize, architecturekit::Schema`, and implements `Kind` and `Authorized`.
  - `#[actor(scope = <BC>, type = human | system, backed_by = [<ExternalSystem>, ...])]` — Defaults `type` to `human` (`backed_by` is permitted only when `type = system`); implements `Kind`, `Actor`, and `ActorInBoundedContext`.
  - `#[entity(scope = <BC>, identified_by = schema(<field>) | static("<val>"))]` — Defaults `identified_by` to `schema(id)`, derives `Clone, Debug, PartialEq, Serialize, Deserialize, architecturekit::Schema`, and implements `Kind`, `Identified` (`HAS_LIFECYCLE = false`), and `Entity`.
  - `#[value_object(scope = <BC>)]` — Derives `Clone, Debug, PartialEq, Serialize, Deserialize`, implements `architecturekit::Schema` (deriving on structs and generating string-enum JSON Schemas on unit-variant enums while rejecting non-unit variants), and implements `Kind` and `ValueObject`.
  - `#[domain_service(scope = <BC>)]` — Implements `Kind` and `DomainService`.
- **Cross-Context & Domain Integration Macros** (`src/lib.rs`, `src/integration.rs`; `delivery_guarantee = at_least_once | at_most_once` defaults to `at_least_once` when `idempotency` is set else `at_most_once`, and `idempotency` accepts `<owner>`, `<owner>("...")`, or `idempotency(owner = <owner>, strategy = "...")`):
  - `#[policy(scope = <Domain>, handles = [<Event>, ...], emits = [<Command>, ...], delivery_guarantee = ..., idempotency = ...)]` — Requires non-empty `handles` and `emits`; generates `<Name>Events`, `<Name>Commands`, `EventConsumer`, and `Policy` dispatching to `React<E>`.
  - `#[event_handler(scope = <Domain>, handles = [<Event>, ...], external_systems = [<Ext>, ...], delivery_guarantee = ..., idempotency = ..., error = <Err>)]` — Requires non-empty `handles` (`error` defaults to `architecturekit::DomainError`); generates `<Name>Events`, `EventConsumer`, and `EventHandler` dispatching to `Handle<E>`.
  - `#[process_manager(scope = <Domain>, correlated_by = event_field(<f>) | event_subject, starts_when = [<Event>, ...], handles = [...], emits = [...], timers = [<Timer>(after(<unit> = <u64>)) | <Timer>(at = <f>), ...], ends_when = <expr>, delivery_guarantee = ..., idempotency = ...)]` — Requires non-empty `starts_when` and at least one entry in `emits` or `timers` (`<unit>` in `seconds | minutes | hours | days | weeks | months | years`); auto-derives `Serialize, Deserialize` on the state struct and generates `<Timer>` unit structs (`<Timer>::set()`, `<Timer>::cancel()`, `ProcessTimer`), `<Name>Events`, `<Name>Commands` (`ProcessCommand`), `EventConsumer`, and `ProcessManager` (`OnEvent<E>`, `OnTimer<T>`).
  - `#[external_system(scope = <Domain>, direction = inbound | outbound | bidirectional, category = "...")]` — Implements `Kind`, `ExternalSystem`, `ExternalSystemInDomain`, and `MappingEndpoint`.
  - `#[context_mapping(type = <pattern>, ...)]` — Supports asymmetric patterns (`customer_supplier` with `customer`/`supplier`, `conformist` with `conformist`/`upstream`, `anti_corruption_layer` with `downstream`/`upstream`, `open_host_service` with `host`/`consumer`, `published_language` with `publisher`/`consumer`) and symmetric patterns (`shared_kernel | partnership | separate_ways` with `participants = [<BC1>, <BC2>]`); implements `Kind` (`Scope = ()`) and `ContextMapping`.
- **Schema & Events Derive Macros** (`src/lib.rs`, `src/schema.rs`):
  - `#[derive(Schema)]` — Implements `chromatofoor::architecturekit::Schema` for structs and unit-variant enums without requiring a direct `architecturekit` dependency in downstream crates.
  - `#[derive(Events)]` — Implements `chromatofoor::architecturekit::Events` for non-empty event sum-type enums without requiring a direct `architecturekit` dependency in downstream crates.

## Invariants
- **Strict Rust Safety & Lint Baseline** (`Cargo.toml`): Inherits workspace lints enforcing `#![deny(unsafe_code)]`, `clippy::pedantic`, and `deny(unwrap_used, expect_used, panic, todo, unimplemented)`.
- **Compile-Time Hierarchical Scope & Boundary Checks** (`src/common.rs`, `src/domain.rs`, `src/bounded_context.rs`, `src/integration.rs`):
  - Concatenates `Kind::TOPIC` at compile time (`<Scope as Kind>::TOPIC + "/" + NAME`) and enforces `assert_bounded_context_in_domain` on `#[subdomain]`, `assert_aggregate_event_scope` on `#[event]` enums vs. `assert_freestanding_event_scope` (`EventStructScope`) on `#[event]` structs, `assert_event_in_bc` on `#[dynamic_consistency_boundary]` and `#[read_model]`, `assert_actor_in_bc` on `actors`, `assert_command_scope` on `#[command]`, `assert_event_in_domain` on `#[policy]`, `#[event_handler]`, and `#[process_manager]`, and `assert_command_in_domain` on `#[policy]` and `#[process_manager]`.
  - Enforces `assert_external_system_in_domain` plus direction checks (`inbound | bidirectional` on `#[actor(type = system, backed_by = ...)]`, rejecting `backed_by` when `type = human`; `outbound | bidirectional` on `#[event_handler(external_systems = ...)]`).
  - Enforces `#[context_mapping]` endpoint types and topic distinctness (`const_str_eq`): asymmetric patterns accept `BoundedContext` or `ExternalSystem` (`assert_mapping_endpoint`), whereas symmetric patterns require exactly 2 distinct `BoundedContext` endpoints (`assert_bounded_context_endpoint`).
- **Compile-Time `Identified` & Lifecycle Verification** (`src/common.rs:identified_impl`, `src/bounded_context.rs:command_impl_block`):
  - Restricts `identified_by` to `state(<field>)`, `command_payload(<field>)`, `schema(<field>)`, `static("<value>")`, or `generated(uuid)` (entities allow only `schema` / `static`; DCBs disallow `state` / `schema`).
  - Verifies struct `state(<field>)` / `schema(<field>)` fields via `FieldAsIdStr`, and asserts `validate_command_id_fields` via `IdFieldProbe` (`Identifier`, `SubjectSegment`, or `Uuid`) on every command.
  - Rejects `#[creates]` / `#[lifecycle(create)]` on tuple variants and emits `Precondition::on_populated_subject(self.subject())` + `Precondition::on_state_read()` on mutation commands targeting `HAS_LIFECYCLE == true` (`#[aggregate]`) scopes, versus `Precondition::on_state_read()` on creation commands and DCBs.
- **Fail-Closed Authorization & Pre-Decide Validation** (`src/common.rs:authorized_impl_block`, `src/bounded_context.rs:command`): Commands and queries without declared `actors` emit `ALLOWED_ACTORS = &[]` (denying actor-checked dispatch by default); when `validate` is enabled on `#[command]` (or `#[derive(Validate)]` is present, injecting `#[validate(crate = "chromatofoor::validator")]`), `validator::Validate::validate` runs before `Command::decide`.
- **Idempotency & Process Manager Contracts** (`src/integration.rs`): `delivery_guarantee = at_least_once` without an explicit `idempotency` owner (`self | self_managed | downstream | infrastructure | none | not_required`) fails at compile time; `#[process_manager]` rejects `after(<unit> = 0)`, verifies `AsTimerTimestamp` on `at = <field>` timers, deduplicates monotonic `event_id <= last_event_id`, flushes pending outbox commands before new events, and clears active timers once `ends_when` evaluates to `true`.

## Side Effects
- **Compile-Time Expansion**: None. All procedural macro expansions are pure in-memory token stream transformations (`syn` / `quote`) with zero disk, network, or environment I/O.
- **Generated Runtime Glue**: Expanded `CommandScope`, `Projection`, `Policy`, `EventHandler`, and `ProcessManager` implementations delegate runtime store reads/writes, outbox flushes, and timer supervision (`chrono::Utc::now()` for relative `after(...)` deadlines) to `chromatofoor` and `architecturekit::Store`.
